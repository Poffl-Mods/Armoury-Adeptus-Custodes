# Guardian Spear

A standalone Guardian Spear mod for *Warhammer 40,000: Rogue Trader*.

The weapon combines a staff-based melee profile with an integrated single-shot
bolter profile. It includes a custom FBX model, Owlcat-compatible materials,
melee and ranged abilities, projectile/VFX integration, and a visual firing-pose
controller.

No Deathwatch, MicroPatches, Harmony, or other mod dependency is required.

## Installation

Install the latest `AstartesCustodes.zip` with the Rogue Trader mod manager and
enable **Guardian Spear Prototype**.
